# Contributing

Este repositório não está aceitando contribuições externas no momento.

Se você quer modificar o pente-fino:
- Faça um fork (a Apache 2.0 permite)
- Modifique conforme suas necessidades
- Documente as mudanças no seu fork (exigência da licença)
- Mantenha o aviso de copyright original

Para reportar problemas críticos de segurança, contato direto: bruno@brbox.net.
